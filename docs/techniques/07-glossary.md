# 07. Bảng thuật ngữ song ngữ (Bilingual Glossary)

| Tiếng Việt | English | Giải thích ngắn |
|---|---|---|
| Máy khách | Client | Trình duyệt của người dùng |
| Máy chủ | Server | Chương trình xử lý yêu cầu |
| Yêu cầu / Phản hồi | Request / Response | Cặp thông điệp HTTP |
| Giao diện lập trình ứng dụng | API (Application Programming Interface) | Cách chương trình nói chuyện với nhau |
| Tuyến đường | Route / Endpoint | URL xử lý một việc |
| Mã trạng thái | Status code | 200, 400, 404... |
| Ứng dụng một trang | SPA (Single Page Application) | Không tải lại trang |
| Trạng thái | State | Dữ liệu hiện tại của giao diện |
| Kết xuất | Render | Biến dữ liệu thành giao diện |
| Mô hình đối tượng tài liệu | DOM (Document Object Model) | Cấu trúc trang mà JS thao tác |
| Ủy quyền sự kiện | Event delegation | Một listener xử lý nhiều phần tử |
| Bất đồng bộ | Asynchronous | Không chặn việc khác |
| Lời hứa | Promise | Kết quả có trong tương lai |
| Biến CSS | CSS variable / custom property | `--accent` |
| Chuyển tiếp | Transition | Đổi mượt giữa hai trạng thái |
| Hoạt ảnh khung chính | Keyframe animation | `@keyframes` |
| Độ trễ | Delay | Chờ trước khi chạy |
| Làm mượt chuyển động | Easing | Đường cong tốc độ |
| Đáp ứng | Responsive | Thích ứng mọi cỡ màn hình |
| Truy vấn phương tiện | Media query | `@media (max-width: 900px)` |
| Lưới / Hộp linh hoạt | Grid / Flexbox | Hai hệ bố cục CSS |
| Phần tử giả | Pseudo-element | `::before`, `::after` |
| Độ ưu tiên selector | Specificity | Luật quyết định CSS nào thắng |
| Khả năng truy cập | Accessibility (a11y) | Dùng được cho mọi người |
| Cơ sở dữ liệu | Database | Nơi lưu dữ liệu |
| Tuần tự hóa | Serialization | Object → chuỗi JSON |
| Ghi nguyên tử | Atomic write | Ghi trọn vẹn hoặc không ghi |
| Khóa luồng | Lock / Mutex | Chỉ một luồng được vào |
| Tranh chấp dữ liệu | Race condition | Hai luồng sửa cùng dữ liệu |
| Đa luồng | Multithreading | Chạy nhiều luồng song song |
| Khóa chính / ID tự tăng | Primary key / Auto-increment | Mã định danh duy nhất |
| Nguồn sự thật duy nhất | Single source of truth | Mỗi dữ liệu lưu một nơi |
| Dữ liệu dẫn xuất | Derived data | Tính từ dữ liệu gốc |
| Xác thực | Authentication | Bạn là ai |
| Phân quyền | Authorization | Bạn được làm gì |
| Băm | Hash | Biến mật khẩu thành chuỗi một chiều |
| Muối | Salt | Chuỗi ngẫu nhiên thêm trước khi băm |
| Phiên | Session | Trạng thái đăng nhập |
| Tấn công XSS | XSS (Cross-Site Scripting) | Chèn script độc vào trang |
| Tấn công CSRF | CSRF (Cross-Site Request Forgery) | Giả mạo yêu cầu |
| Duyệt đường dẫn | Path traversal | Truy cập file ngoài ý muốn bằng `../` |
| Danh sách cho phép | Allowlist / Whitelist | Chỉ cho phép mục trong danh sách |
| Giới hạn tần suất | Rate limiting | Chặn gửi quá nhiều request |
| Hàm thuần | Pure function | Không tác dụng phụ |
| Tác dụng phụ | Side effect | Thay đổi thứ ngoài hàm |
| Tái cấu trúc | Refactoring | Cải thiện code, không đổi hành vi |
| Kiểm thử đơn vị | Unit test | Test từng hàm nhỏ |
| Tích hợp liên tục | CI (Continuous Integration) | Tự chạy test khi push |
| Kiểm soát phiên bản | Version control | Git |
| Cam kết | Commit | Một điểm lưu trong Git |
| Tách mối quan tâm | Separation of concerns | Mỗi phần lo một việc |
| Mô-đun hóa | Modularization | Chia code thành module |
| Phản hồi tức thì | Instant feedback | UI báo ngay kết quả |
| Phân bổ theo tỉ lệ | Proportional allocation | Chia phí theo tỉ lệ đóng góp |
| Làm tròn | Rounding | Làm tròn số tiền |
| Nhập / Xuất | Import / Export | Đưa dữ liệu vào / ra |
